# 🔒 Политика безопасности Threatbit Simple Scanner
> Автор оставляет за собой право вносить изменения в данный текст

📄 Этот документ описывает статус поддержки различных версий утилиты Threatbit Simple Scanner с точки зрения обновлений безопасности.

## ❗ Статус поддержки версий

| Версия программы | Статус поддержки |
|--------------|---------------|
| v1.3 | Активная поддержка |
| v1.2.1 | Ограниченная поддержка |
| v1.2 | Поддержка прекращена |
| v1.1.2 | Поддержка прекращена |
| v1.1.1 | Поддержка прекращена |
| v1.1 | Поддержка прекращена |
| v1.0 | Поддержка прекращена |

## 🔑 Расшифровка статусов

* **Активная поддержка** — для этой версии выпускаются все обновления безопасности и исправления уязвимостей. Рекомендуется к использованию.
* **Ограниченная поддержка** — исправления выпускаются только для критических уязвимостей (CVSS ≥ 7.0). Новые функции или исправления некритических ошибок не добавляются. Пользователям рекомендуется обновиться до последней версии.
* **Поддержка прекращена** — обновления безопасности для этой версии не выпускаются. Использование представляет угрозу безопасности. Необходимо как можно скорее обновиться до поддерживаемой версии.

>[!WARNING]
>
> ### ⚠ О версиях
> Помните, что версии v1.0 и v1.1 были сделаны с помощью **Pyinstaller** и имеют большой вес и меньше детектов. Всё, что выше v1.1.1 будут скомпилированы только с помощью **Nuitka**. Поэтому антивирусные программы могут блокировать использование программы.

>[!CAUTION]
>
>## 📬 Сообщение об уязвимостях
> Если вы обнаружили уязвимость, пожалуйста:
> 1. **Не разглашайте информацию публично** до выхода исправления.
> 2. Используйте [GitHub Security Advisories](https://github.com/2M12/ThreatbitSimpleScanner/security/advisories/new).
> В отчёте укажите: тип уязвимости, шаги для воспроизведения, затронутую версию, возможное влияние.
> После исправления вы будете упомянуты в благодарностях (по желанию).

## ☝ Рекомендации пользователям

Для обеспечения максимальной безопасности системы используйте последнюю версию утилиты из раздела [Releases](https://github.com/2M12/ThreatbitSimpleScanner/releases).

Старые версии могут содержать неустранённые уязвимости и не обеспечивают полную защиту от современных угроз.
